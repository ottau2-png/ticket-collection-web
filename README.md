# 半券コレクション

ライブ・舞台・スポーツなどのチケットの半券を、写真で残して見返すための Web アプリです。
iPhone のホーム画面に追加して、アプリとして使います。

**https://ottau2-png.github.io/ticket-collection-web/**

## できること

- 半券を撮影して、四隅を合わせて切り抜く（斜めに撮っても長方形に補正）
- 公演名・ツアー名・出演者・公演日・開場／開演・会場・席・価格・発券元・コメントを記録
- 一覧：新しい順・古い順・年・出演者・カテゴリー・会場ごと、リスト／ギャラリー、検索
- 全画面で半券をめくって見る（拡大・横向き）
- 出演者の表記ゆれ（略称など）をまとめる
- AI で読み取る：お使いの AI アプリ（Claude・ChatGPT など）に画像を渡し、答えを貼り付けると項目が入る
- バックアップの書き出し・読み込み（画像込みの JSON ファイル1つ）

## 始め方（iPhone）

1. Safari で上の URL を開く
2. 「…」または共有ボタン（□↑）→「共有」→「ホーム画面に追加」
3. **「Webアプリとして開く」をオン**にして「追加」
4. ホーム画面の「半券」アイコンから開く

Safari で開いたまま使うと、しばらく使わないうちにデータが消えることがあります。必ずホーム画面のアイコンから使ってください。
ホーム画面のアプリと Safari はデータが別々です。

## AI で読み取る

アプリが AI に直接つなぐことはありません。お使いの AI アプリを経由します。

1. 半券の登録・編集画面で「AIで読み取る」
2. 「指示文をコピー」→ AI アプリに貼り付ける
3. 「画像を共有」→ 共有メニューで AI アプリを選んで画像を送る
4. AI の答えをコピーして、アプリの答え欄に貼り付ける（または「コピーした答えを読み込む」）→「n項目を反映」

読み取れた項目と件数を確かめてから反映できます。反映すると入力済みの欄も上書きしますが、答えが空の項目は今の値を残します。

- 画像は、あなたが選んだ AI アプリの提供元に送られます。半券には氏名・座席・チケット番号などが写ることがあるので、送ってよいか各自で判断してください。送られた画像の扱いは、各 AI アプリの規約・設定によります
- Claude アプリでの動作を確かめています。ChatGPT の答えを長押しで貼り付けると、アプリが固まることがあります（対応の予定はありません）

## データとバックアップ

- 半券の画像とデータは **この端末の中（ブラウザの保存領域）にだけ** 保存されます。アプリから外部に送ることはありません（共有メニューで自分で送る場合を除く）
- 機種変更・アプリの削除・端末の初期化でデータは消えます。**ときどき設定画面から書き出して**、「ファイル」アプリやクラウドに保存してください
- 書き出したファイルは、設定画面の「バックアップを読み込む」で戻せます（同じ半券は上書き、増えません）
- 半券が3枚以上あって一度も書き出していないとき、または前回の書き出しから30日以上たつと、一覧に案内が出ます

## 動作環境

- iPhone の Safari（ホーム画面に追加した状態）で動作を確かめています
- Android・PC のブラウザでも開けますが、動作は確かめていません
- 一度開けば、機内モードなどオフラインでも使えます

## 開発

ビルドなし（ES モジュール＋同梱の Preact・htm）。GitHub Pages で `main` を公開しています。

```sh
npm ci          # テスト用の fake-indexeddb を入れる
npm test        # node --test
npm run serve   # http://localhost:8765/
```
